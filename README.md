# 🎚️ SoundIsolator — عزل الصوت عن الأغاني والفيديوهات

برنامج محلي بالكامل لفصل الغناء عن الموسيقى (وعكسه) بأحدث نماذج التعلّم العميق.
لا يُرفع أي ملف إلى الإنترنت — المعالجة كلها على جهازك.

---

## ما الذي بُني هنا

| المحرك | المصدر | ما يقدّمه |
|---|---|---|
| **python-audio-separator** | [nomadkaraoke/python-audio-separator](https://github.com/nomadkaraoke/python-audio-separator) | يشغّل نماذج **BS-Roformer / Mel-Band Roformer / MDX23C / UVR-MDX-NET** — أعلى دقة متاحة اليوم لعزل الغناء |
| **Demucs v4** | [adefossez/demucs](https://github.com/adefossez/demucs) | Hybrid Transformer Demucs — فصل إلى ٤ أو ٦ أجزاء (غناء، طبول، باص، جيتار، بيانو، أخرى) |
| **FFmpeg** | Gyan build | فك ترميز أي صيغة دخل، وترميز الإخراج، وإعادة تركيب الفيديو |

النماذج تُنزَّل تلقائيًا عند أول استخدام إلى `models/`.

## التثبيت (مرة واحدة)

```bash
powershell -ExecutionPolicy Bypass -File D:\SoundIsolator\install.ps1
```

ينشئ `.venv` معزولة، ويثبّت PyTorch بدعم CUDA، والمحركين، والواجهة، ثم يجري فحصًا ذاتيًا.

## التشغيل

**الوضع البسيط** — بلا أي إعدادات:
```bash
D:\SoundIsolator\run.bat
```
أفلت الملف ← اضغط **ابدأ العزل** ← يظهر **الخلّاط**.

### الخلّاط

المساران يعملان **معًا ومتزامنَين تمامًا**، وتتحكم بهما أثناء التشغيل:

| العنصر | ماذا يفعل |
|---|---|
| زر التشغيل / مفتاح المسافة | يشغّل ويوقف المسارين معًا |
| شريط التقدّم | يحرّك المسارين لنفس اللحظة |
| منزلق كل مسار | يرفع أو يخفض مستواه من 0% إلى 100% |
| زر الكتم | يكتم مسارًا بالكامل — وإلغاء الكتم **يعيد المستوى السابق** لا 100% |
| كاريوكي | موسيقى فقط (يكتم الغناء) |
| أكابيلا | غناء فقط (يكتم الموسيقى) |
| متوازن | يعيد الاثنين إلى 100% |
| **احفظ المزيج على جهازي** | يكتب ملفًا واحدًا بالمستويات التي ضبطتها بالضبط |

المزيج المحفوظ **مطابق تمامًا لما سمعته** — نفس معاملات الكسب تُطبَّق على العيّنات،
والاسم يوثّق النِسَب (مثال: `song__mix_30v-100m.wav`). لو تجاوزت الذروة الحدّ
يُخفَّض المستوى تلقائيًا بدل القصّ المشوِّه.

### آلات منفردة

حين يقع الاختيار التلقائي على نموذج **Demucs** (يحدث عادة للمقاطع القصيرة
في وضع «جودة عالية» — راجع الجدول أدناه)، يظهر صندوق تنزيل إضافي فيه كل
آلة على حدة: الطبول، الباص، الجيتار، البيانو، وما تبقّى — بجانب الغناء
والموسيقى المُجمَّعة في المشغّل، لا بدلًا عنهما. مع نماذج الغناء/الموسيقى
الثنائية (Roformer وغيرها) لا تظهر هذه الآلات لأن النموذج نفسه لا ينتجها.

الموسيقى المُجمَّعة في المشغّل تُبنى بالطرح الطوري (الأصل − الغناء) لا
بجمع أجزاء الآلات — قِسته فعليًا مقابل جمع أجزاء Demucs النظيفة على عيّنة
مرجعية: الطرح أفضل بفارق طفيف (21.34dB مقابل 21.09dB) لأنه يلتقط ما لا
تفصله أقنعة الآلات بدقة (صدى، تفاعلات دقيقة بين الآلات). الآلات المنفردة
المتاحة للتنزيل تبقى مخرجات Demucs الخام كما هي — أنظف لكل آلة بمفردها.

**الوضع المتقدّم** — كل المقابض:
```bash
D:\SoundIsolator\run-advanced.bat
```

**سطر الأوامر** — للأتمتة:
```bash
D:\SoundIsolator\run-cli.bat "D:\Music\song.mp3" --model roformer_bs --stems both --format wav24
```

## أمثلة جاهزة

```bash
:: عينة تجريبية مدمجة (يولّدها البرنامج بنفسه) ثم يعزلها
run-cli.bat --demo

:: أنظف غناء ممكن
run-cli.bat song.mp3 --model roformer_bs --stems vocals --format flac24

:: موسيقى فقط (كاريوكي) بأقل بقايا غناء
run-cli.bat song.mp3 --model mdxnet_inst_hq3 --stems instrumental

:: فيديو: احذف الغناء وأعد تركيب الفيديو بالموسيقى فقط
run-cli.bat clip.mp4 --stems instrumental --remux

:: فصل كامل إلى ٦ أجزاء
run-cli.bat song.wav --model htdemucs_6s --stems all

:: ألبوم كامل دفعة واحدة إلى MP3 320
run-cli.bat --folder "D:\Album" -r --model mdx23c --format mp3_320

:: عرض كل النماذج وحالة كرت الشاشة
run-cli.bat --list-models
```

## آلية العمل

```
ملف دخل (MP3/WAV/FLAC/M4A/OGG/MP4/MOV/MKV…)
   │
   ├─ 1. ffmpeg → WAV float32 غير مضغوط        لا نبدأ من مصدر متضرّر
   │
   ├─ 2. النموذج العصبي
   │      • Roformer/MDX : STFT → قناع طيفي مُتعلَّم بـ Attention → iSTFT
   │      • Demucs v4    : فرعان متوازيان (موجة + طيف) يلتقيان في Transformer
   │
   ├─ 3. «العكس» بالطرح الطوري
   │      موسيقى = الخليط الأصلي − الغناء المعزول   (في نطاق الزمن)
   │      يحافظ على كامل الطيف بلا تلوين، بدل توليد الموسيقى من الصفر
   │
   ├─ 4. معالجة نهائية: تسوية ذروة اختيارية / حماية من القص
   │
   └─ 5. إخراج: WAV/FLAC 24-bit بلا فقد، أو MP3/AAC/Opus عبر ffmpeg
                (+ إعادة تركيب داخل الفيديو الأصلي بلا إعادة ترميز للصورة)
```

## مقابض التحكّم

| المقبض | ماذا يفعل | متى تغيّره |
|---|---|---|
| **النموذج** | يحدّد التقنية والأجزاء | حسب الهدف — انظر الجدول أدناه |
| **وضع العزل** | غناء / موسيقى / الاثنان / كل الأجزاء | دائمًا |
| **مستوى الدقة (shifts/TTA)** | يكرّر الاستدلال بإزاحات زمنية ويتوسّط النتائج | ٢–٣ للإخراج النهائي فقط (الوقت يتضاعف) |
| **طول المقطع** | يقسّم الصوت لتقليل ذاكرة الكرت | خفّضه عند خطأ ذاكرة |
| **التداخل** | تداخل المقاطع عند إعادة التجميع | ارفعه لو سمعت طقطقة عند الوصلات |
| **حجم الدفعة** | عدد المقاطع المعالجة معًا | ارفعه لو الذاكرة تسمح (أسرع) |
| **عتبة التسوية** | تسوية داخلية قبل الاستدلال | خفّضها لو ظهر تشويه في التسجيلات العالية |
| **الطرح الطوري** | يستخرج المقابل بالطرح بدل مجموع الأجزاء | أبقه مفعّلًا — أدقّ طيفيًا |

## أي نموذج أختار؟

| الهدف | النموذج | المفتاح |
|---|---|---|
| أنظف غناء ممكن | BS-Roformer | `roformer_bs` |
| بديل بجودة مماثلة | Mel-Band Roformer | `roformer_melband` |
| توازن جودة/سرعة (موصى به لكرت 4GB) | MDX23C-InstVoc HQ | `mdx23c` |
| موسيقى بلا بقايا غناء | UVR-MDX-NET Inst HQ 3 | `mdxnet_inst_hq3` |
| فصل الطبول/الباص/الآلات | Demucs htdemucs_ft | `htdemucs_ft` |
| ٦ أجزاء (+جيتار +بيانو) | Demucs htdemucs_6s | `htdemucs_6s` |
| إزالة صدى من غناء معزول | DeEcho-DeReverb | `dereverb` |
| فصل الصوت الرئيسي عن الكورال | Karaoke 6_HP | `karaoke` |

**تسلسل احترافي للنتيجة القصوى:**
`roformer_bs` → استخرج الغناء، ثم مرّره على `dereverb`، ثم على `karaoke` لفصل الدوبلات.

## حلّ المشاكل

| المشكلة | الحل |
|---|---|
| `CUDA out of memory` | البرنامج يقلّل المقطع تلقائيًا ثم ينتقل للمعالج. يدويًا: طول المقطع ٤s، حجم الدفعة ١ |
| تنزيل النموذج بطيء/متوقف | النماذج من GitHub؛ تحقّق من الاتصال. تُحفظ في `models/` ولا تُنزَّل ثانية |
| `ffmpeg not found` | `winget install Gyan.FFmpeg` ثم أعد فتح الطرفية |
| طقطقة عند الوصلات | ارفع التداخل إلى 0.5 |
| بقايا غناء في الموسيقى | جرّب `mdxnet_inst_hq3`، أو ارفع مستوى الدقة إلى ٣ |
| المعالجة بطيئة جدًا | تأكّد أن الجهاز `cuda` وليس `cpu` — يظهر أعلى الواجهة |
| نماذج ONNX تعمل على المعالج | `onnxruntime-gpu` يجب أن يبقى على `1.20.2` — الإصدارات الأحدث مبنية على CUDA أعلى من 12.4 فتسقط للمعالج بصمت |

## اختيار التقنية (الوضع البسيط)

الوضع البسيط يعرض **خيارين واضحين** قبل أن تضغط «ابدأ العزل»، مع الوقت
المتوقّع لكل منهما محسوبًا لملفّك تحديدًا:

- **متوازن — أسرع** (`AUTO_TIME_BUDGET_S = 30s` في [engine.py](src/engine.py)):
  أعلى دقة تُنجَز خلال ٣٠ ثانية معالجة. لملف طويل هذا يعني عمليًا أسرع نموذج متاح.
- **جودة عالية — أبطأ** (`QUALITY_TIME_BUDGET_S = 180s` أي ٣ دقائق):
  أعلى دقة تُنجَز خلال ٣ دقائق — سقف صريح لا يُتجاوَز. على مقطع قصير جدًا
  فقط يحصل على أدقّ نموذج في المكتبة (`roformer_v1`)، وأغلب الملفات
  تنزلق تلقائيًا لنموذج أسرع بوضوح — لا يزال أدقّ من وضع السرعة.

كلا الوضعين يستخدمان **نفس آلية الاختيار** (أعلى SDR ينهي العمل ضمن الميزانية)
بفارق السقف الزمني فقط — فالمنطق ذاته الذي اخترته لك محسوب، لا تخمين.

على GTX 1650 (4 GB) يعطي هذا:

| طول الملف | متوازن (٣٠ث) | جودة عالية (٣د) |
|---|---|---|
| ٢١ ثانية | `mdxnet_inst_hq3` (~16 ث) | `htdemucs_ft` (~107 ث) |
| دقيقة | `kim_vocal_2` (~29 ث) | `htdemucs` (~78 ث) |
| أغنية ٤ دقائق | `kim_vocal_2` (~1.6 د) | `mdxnet_inst_hq3` (~1.9 د) |
| ١٠ دقائق فأكثر | `kim_vocal_2` | `kim_vocal_2` (يتقارب صدقًا — لا نموذج آخر يفي بـ٣ دقائق) |

`roformer_v1` وحده — أعلى SDR في السجل (12.60) — يحتاج **~18× طول الملف**؛
أغنية ٤ دقائق تعني ~72 دقيقة معالجة، فلا يُستخدَم مباشرة على ملفات كاملة
حتى في وضع الجودة، بل يُحجَز تلقائيًا للمقاطع القصيرة جدًا (أقل من ~10
ثوانٍ) حيث ينهي العمل ضمن سقف الـ٣ دقائق فعلًا.

على كرت أقوى تنزاح كل الجداول نحو النماذج الأدقّ تلقائيًا، لأن السقف
الزمني ثابت والقدرة الحاسوبية أعلى.

## أداء مُقاس فعليًا (GTX 1650 · 4 GB)

مقطع ٢١ ثانية:

| النموذج | الزمن | SDR على العيّنة |
|---|---|---|
| `kim_vocal_2` (ONNX على الكرت) | **8 ث** | — |
| `htdemucs` | **25 ث** | — |
| `mdx23c` | **65 ث** | 3.9 dB |
| `roformer_v1` | **7–8 د** | **30.6 dB** |

الفرق بين آخر صفّين هائل — هذا بالضبط ما يمنحك خيار «جودة عالية» على
المقاطع القصيرة، وما يمنعه على أغنية كاملة (الوقت غير معقول). للحصول على
`roformer_v1` عنوةً على ملف طويل رغم الوقت، استخدم الوضع المتقدّم
(`run-advanced.bat`) واختره يدويًا.
